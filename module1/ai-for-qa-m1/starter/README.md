# Starter skeletons

Two small exercises with the signatures, types and tests in place and the logic replaced by `TODO`.
Tests fail on a fresh checkout; the goal is to turn them green.

- `token-cost/`: word and token estimation, then the per-sprint ROI arithmetic.
- `sanitize/`: pattern detectors (with a Luhn check) and format-preserving masking.

```
npm run test:starter
```

The finished versions are in `src/`. Reference solutions are kept in the instructors' repository.
